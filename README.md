# MD to PDF

Web app sederhana untuk menulis atau mengunggah Markdown, melihat preview langsung, mengatur halaman, dan menyimpan hasil sebagai PDF.

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

## Pemeriksaan

```bash
npm test
npm run lint
```

## Deploy ke Vercel

1. Push repository ini ke GitHub.
2. Pilih **Add New Project** di Vercel.
3. Impor repository GitHub tersebut.
4. Vercel akan mendeteksi Vite dan menggunakan konfigurasi di `vercel.json`.
5. Pilih **Deploy**.

Tidak ada environment variable, backend, atau database yang dibutuhkan.
